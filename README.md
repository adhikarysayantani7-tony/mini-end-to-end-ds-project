# Mini End-to-End Data Science Project: Employee Attrition Prediction

## Project Overview
An end-to-end data science workflow covering data collection, cleaning, EDA, modeling, evaluation, and insight generation on employee HR records.

## Repository Structure
- `README.md`: Project overview and usage guide
- `requirements.txt`: Python dependencies
- `data/raw_dataset.csv`: Raw HR dataset with duplicates and missing values
- `data/cleaned_dataset.csv`: Final cleaned dataset
- `notebooks/end_to_end_project.ipynb`: Complete end-to-end Jupyter Notebook
- `docs/project_report.md`: Project report (Problem → Approach → Results → Insights)
